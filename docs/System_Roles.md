# RaceDay System Roles

## Organiser

The Organiser is responsible for managing race events.

An Organiser can:

- Create events
- Edit events
- Delete events
- Create and manage event categories
- View event enrolments
- Capture participant results
- View participant information related to their events

## Participant

The Participant uses RaceDay to enter and track races.

A Participant can:

- Register for an account
- Log in
- View their profile
- Browse upcoming events
- View event categories
- Enter an event
- View their own enrolments
- View their own results

## Role Separation

RaceDay uses two roles:

- Organiser
- Participant

The role assigned to a user determines which functionality they can access.

Role-based access control will be enforced at API level in Part 2 and reflected in the MVC application in Part 3.
